## 为什么这么做（根因）

你之前已经做过的方案 B（禁用服务 + AU 注册表）**对 Insider Dev 通道无效**，因为该通道的更新走 `InstallService` 的 `ScanForUpdates` 计划任务，绕过被禁用的 `wuauserv` 直接调用 Update Session Orchestrator。本次修复封堵了这个绕过路径，并用 `TargetReleaseVersion` 锁定当前 Build，即使有更新推送也禁止升级到更高版本。

## 验证方法（可随时复跑）

```powershell
# 1. 计划任务应为 Disabled

# 2. 版本锁定应生效
Get-ItemProperty 'HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate' | Select TargetReleaseVersion,TargetReleaseVersionInfo

# 3. 观察下次是否还有自动下载/安装
Get-WinEvent -FilterHashtable @{LogName='System'; ProviderName='Microsoft-Windows-WindowsUpdateClient'} -MaxEvents 5 | Select TimeCreated,Id,@{N='原因';E={$_.Message.Split("`n")[0]}}
```

## 影响范围

- ✅ **保留** Insider Dev 通道身份（未退出预览体验计划）
- ✅ 仍可**手动**去"设置 → Windows Update → 检查更新"主动安装需要的补丁
- ⚠️ 不再自动接收 Build 升级，停留在 29639.1000 直到你手动解除锁定
- ⚠️ 安全累积更新也不会自动安装，需定期手动检查（建议每周一次）

## 回滚方案

如需恢复自动更新（例如想升级到新 Build），以管理员 PowerShell 执行：

```powershell
Enable-ScheduledTask -TaskName 'ScanForUpdates' -TaskPath '\Microsoft\Windows\InstallService\'
Enable-ScheduledTask -TaskName 'ScanForUpdatesAsUser' -TaskPath '\Microsoft\Windows\InstallService\'
Remove-ItemProperty -Path 'HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate' -Name TargetReleaseVersion,TargetReleaseVersionInfo,ProductVersion -ErrorAction SilentlyContinue
```
