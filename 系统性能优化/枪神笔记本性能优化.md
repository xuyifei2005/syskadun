## 一、背景与问题

| 问题 | 现象 |
|------|------|
| 工作模式无法切换 | Fn+F5 失效，无法在静音/平衡/增强模式间切换 |
| 历史遗留 | 曾卸载华硕全家桶服务（因频繁蓝屏），导致 Fn 组合键失效 |
| CPU 过热 | G-Helper 显示 CPU 98°C，后台存在异常占用进程 |

## 二、工作模式修复（根因方案）

**方案**：使用 G-Helper（开源轻量，v0.283.0）替代华硕全家桶，无蓝屏风险。

- 安装路径：`D:\XUYIFEI\syskadun\tools\GHelper\GHelper.exe`
- 已开启开机自启，接管性能模式 / 显卡模式 / 屏幕刷新率 / 键盘灯效
- ✅ 验证结果：Fn+F5 模式切换恢复正常，CPU 风扇曲线可控
