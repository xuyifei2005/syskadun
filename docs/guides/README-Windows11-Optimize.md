# Windows 11 性能优化指南

## 📋 适用场景

本优化方案专为以下使用场景设计：
- ✅ 编程开发（多 IDE、多项目并行）
- ✅ 视频创作（视频剪辑、渲染）
- ✅ 图形处理（Photoshop、Illustrator 等）
- ✅ 多任务处理（同时运行多个应用程序）

## 🎯 系统要求

- 操作系统：Windows 11
- 内存：32GB 或以上（推荐 64GB+）
- 存储：SSD 固态硬盘

---

## 🚀 快速开始

### 步骤 1：创建系统还原点（必做）

**在执行任何优化前，先创建系统还原点！**

```powershell
# 以管理员身份运行 PowerShell
cd d:\syskadun
.\create-restorepoint.ps1
```

### 步骤 2：执行一键优化

```powershell
# 执行所有优化（推荐）
.\win11-optimize.ps1

# 仅执行系统清理
.\win11-optimize.ps1 -CleanOnly

# 仅执行性能优化
.\win11-optimize.ps1 -PerformanceOnly
```

### 步骤 3：监控性能

```powershell
# 启动性能监控
.\performance-monitor.ps1

# 导出性能日志
.\performance-monitor.ps1 -ExportLog
```

## 📁 脚本说明

### 1. create-restorepoint.ps1 - 创建系统还原点

**功能：**
- 创建系统还原点，以便优化失败时恢复
- 自动命名还原点（包含时间戳）

**使用方法：**
```powershell
# 右键点击 PowerShell，选择"以管理员身份运行"
cd d:\syskadun
.\create-restorepoint.ps1
```

**还原系统方法：**
1. 搜索并打开"创建还原点"
2. 点击"系统还原"按钮
3. 选择对应的还原点

---

### 2. win11-optimize.ps1 - 系统优化主脚本

**功能：**
- 清理系统垃圾文件
- 优化性能设置
- 分析启动项

**优化内容：**

#### 阶段 1：系统清理
- ✅ Windows 更新缓存清理
- ✅ 临时文件清理
- ✅ 传输优化缓存清理
- ✅ 回收站清空
- ✅ Windows.old 检测

#### 阶段 2：性能优化
- ✅ 禁用休眠（节省 10-30GB 空间）
- ✅ 启用卓越性能模式
- ✅ 优化虚拟内存（64GB 内存推荐 4-8GB）
- ✅ 禁用窗口透明度
- ✅ 优化系统响应优先级
- ✅ 禁用 8.3 文件名创建
- ✅ 检查并启用 TRIM

#### 阶段 3：启动项分析
- 列出所有启动项
- 提供禁用建议

**参数说明：**
- `-CleanOnly`：仅执行清理
- `-PerformanceOnly`：仅执行性能优化
- `-All`：执行所有优化（默认）
- `-Help`：显示帮助信息

---

### 3. performance-monitor.ps1 - 性能监控

**功能：**
- 实时监控 CPU、内存、磁盘使用率
- 显示资源占用 Top 5 进程
- 支持导出性能日志

**使用方法：**
```powershell
# 基础监控（每 2 秒刷新）
.\performance-monitor.ps1

# 自定义刷新间隔（5 秒）
.\performance-monitor.ps1 -Interval 5

# 运行指定时长（60 秒）
.\performance-monitor.ps1 -Duration 60

# 导出日志到 CSV
.\performance-monitor.ps1 -ExportLog
```

**参数说明：**
- `-Interval`：刷新间隔（秒），默认 2 秒
- `-Duration`：运行时长（秒），0=持续运行
- `-ExportLog`：导出性能日志到 CSV 文件

## 🔧 手动优化建议

### 1. 禁用不必要的启动项

**方法 1：任务管理器**
1. `Ctrl + Shift + Esc` 打开任务管理器
2. 切换到"启动"选项卡
3. 右键禁用不需要的应用

**建议禁用的应用：**
- ❌ 云存储同步（OneDrive、Dropbox）
- ❌ 聊天工具（微信、QQ、Discord）
- ❌ 游戏平台（Steam、Epic）
- ❌ 媒体工具（Spotify、iTunes）

**建议保留的应用：**
- ✅ 杀毒软件（Windows Defender）
- ✅ 硬件驱动相关（音频、显卡）
- ✅ 必需的业务软件

---

### 2. 调整视觉效果

1. 右键"此电脑" -> 属性
2. 点击"高级系统设置"
3. 性能 -> 设置
4. 选择"调整为最佳性能"
5. **勾选**"平滑屏幕字体边缘"（保持字体清晰）

---

### 3. 存储感知设置

1. 设置 -> 系统 -> 存储
2. 开启"存储感知"
3. 配置自动清理规则：
   - 临时文件：每天清理
   - 回收站：30 天后清理
   - 下载文件夹：每周清理

---

### 4. 游戏模式（推荐开启）

1. 设置 -> 游戏 -> 游戏模式
2. 开启游戏模式

**作用：** 优化系统资源分配，即使不玩游戏也建议开启

---

### 5. 硬件加速 GPU 计划

1. 设置 -> 系统 -> 屏幕 -> 图形设置
2. 开启"硬件加速 GPU 计划"
3. **需要重启系统**

---

## 💻 开发环境专项优化

### 1. Docker/WSL2 内存限制

编辑 `C:\Users\你的用户名\.wslconfig`：

```ini
[wsl2]
memory=32GB
processors=8
swap=8GB
```

### 2. 浏览器优化

**Chrome/Edge：**
1. 设置 -> 性能
2. 开启"睡眠标签页"
3. 设置标签页闲置时间：5 分钟

**限制后台扩展：**
1. 设置 -> 扩展
2. 禁用不常用的扩展

### 3. 定期清理开发缓存

```powershell
# npm 缓存
npm cache clean --force

# .NET NuGet 缓存
dotnet nuget locals all --clear

# Rust Cargo 缓存
cargo clean

# Gradle 缓存
rm -rf ~/.gradle/caches
```

### 4. 使用 Process Lasso 管理进程优先级

**下载地址：** https://bitsum.com/

**设置方法：**
1. 安装并运行 Process Lasso
2. 右键开发工具进程 -> 优先级 -> 高
3. 设置 CPU 亲和性（可选）

## 📞 常见问题

### Q1: 禁用休眠后无法使用休眠功能？
**A:** 如需恢复休眠，运行：
```powershell
powercfg -h on
```

### Q2: 优化后系统出现异常？
**A:** 
1. 使用系统还原点恢复
2. 检查事件查看器（`eventvwr.msc`）
3. 回滚最近的驱动更新

### Q3: 虚拟内存设置多少合适？
**A:** 
- 32GB 内存：初始 2GB，最大 4GB
- 64GB 内存：初始 4GB，最大 8GB
- 128GB 内存：初始 8GB，最大 16GB

### Q4: 清理后 C 盘空间还是不足？
**A:** 
1. 使用 WizTree 分析大文件
2. 移动大型软件到其他盘
3. 使用符号链接迁移用户目录
