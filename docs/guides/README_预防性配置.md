## 🚀 快速开始（3 步配置）

### 方法 1：使用快速菜单（推荐）

**步骤 1**: 双击运行 `quick_config_menu.bat`

**步骤 2**: 选择 `[1] Run C: Drive Monitor` 查看当前状态

**步骤 3**: 选择 `[3] Open Configuration Guide` 打开配置指南

### 方法 2：手动执行

**步骤 1**: 打开 PowerShell，进入目录
```powershell
cd d:\syskadun
```

**步骤 2**: 运行监控脚本
```powershell
.\monitor_c_drive.ps1
```

**步骤 3**: 阅读总结报告
```powershell
code PREVENTIVE_OPTIMIZATION_SUMMARY.md
```

## 📋 配置流程

### 第一阶段：立即执行（10 分钟）

1. **运行监控脚本** - 查看当前 C 盘状态
   ```powershell
   .\monitor_c_drive.ps1
   ```

2. **配置 Windows 存储设置**
   - 打开：设置 → 系统 → 存储 → 高级存储设置
   - 将所有"保存新内容的地方"改为 D 盘

3. **运行一次清理**

   - 预计释放：2.46GB

6. **配置常用软件**
   - 浏览器下载位置
   - 微信/QQ 文件位置

7. **Docker 数据迁移** - 参考 `docker_migration_guide.md`
   - 预计释放：50-100GB

8. **配置任务计划程序**
   - 自动运行监控脚本（每天）
   - 自动运行清理脚本（每周）

## 🔧 常见问题

### Q1: 如何查看 C 盘当前状态？
**A**: 运行监控脚本
```powershell
.\monitor_c_drive.ps1
```
或双击 `quick_config_menu.bat`，选择选项 [1]

### Q2: 清理脚本安全吗？
**A**: 安全。只清理临时文件、缓存等可安全删除的内容。

### Q3: 配置后新应用还是安装到 C 盘怎么办？
**A**: 某些软件会忽略 Windows 设置。安装时手动选择"自定义安装"，路径改为 D 盘。

### Q4: 需要管理员权限吗？
**A**: 部分操作需要（如虚拟内存配置）。脚本会以管理员身份运行。

### Q5: 多久运行一次清理脚本？
**A**: 建议每周一次。可通过任务计划程序自动执行。
