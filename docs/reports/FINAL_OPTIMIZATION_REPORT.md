## 📋 待用户手动执行的操作

### 1. 移动虚拟内存到 D 盘（可释放 4-8GB）

**原因**: 需要管理员权限，自动执行受限

**操作步骤**:
1. 右键"此电脑" → "属性"
2. "高级系统设置" → "高级" → "性能" → "设置"
3. "高级" → "虚拟内存" → "更改"
4. 取消"自动管理所有驱动器的分页文件大小"
5. 选择 C 盘 → "无分页文件" → "设置"
6. 选择 D 盘 → "系统管理的大小" → "设置"
7. 确定后重启电脑

**详细指南**: 参考 `d:\syskadun\pagefile_instructions.ps1`

### 2. 迁移 ComfyUI 模型到 D 盘（可释放 2.46GB）

**原因**: 安全限制无法自动复制到 D 盘

**操作步骤**:
1. 在 D 盘创建：`D:\ComfyUI\models`
2. 复制 `C:\Users\xuyif\Documents\ComfyUI\models\*` 到新位置
3. 验证复制完成后删除原文件夹
4. 以管理员身份运行 PowerShell 创建符号链接：
   ```powershell
   New-Item -ItemType SymbolicLink -Path "C:\Users\xuyif\Documents\ComfyUI\models" -Value "D:\ComfyUI\models"
   ```

**详细指南**: 参考 `d:\syskadun\comfyui_migration_guide.md`

### 3. 配置新应用默认安装到 D 盘

**操作步骤**:
1. 打开 设置 → 系统 → 存储
2. 点击"更改新的内容保存位置"
3. "新的应用将保存到" 选择 D 盘
4. 点击"应用"

**详细指南**: 参考 `d:\syskadun\app_install_location_guide.md`

### 4. Docker 数据完全迁移到 D 盘（可释放 50-100GB）

**原因**: Docker 使用 WSL2 后端，需要迁移整个虚拟磁盘

**详细指南**: 参考 `d:\syskadun\docker_migration_guide.md`

## ⚠️ 重要提示

### 已删除的系统文件

1. **Windows.old** - 无法回退到之前的 Windows 版本
2. **休眠文件** - 无法使用休眠功能（睡眠仍可用）
3. **内存转储文件** - 如发生蓝屏，需重新生成
4. **Docker 容器** - 已停止的容器被清理，需要时重新构建

### 建议定期执行

1. **Docker 清理**（每周）
   ```powershell
   docker system prune -f
   ```

2. **临时文件清理**（每月）
   ```powershell
   Remove-Item -Path "$env:TEMP\*" -Recurse -Force
   ```

3. **开启存储感知**
   - 设置 → 系统 → 存储 → 开启存储感知
   - 自动清理临时文件和回收站
