- **虚拟化服务**：Hyper-V主机计算服务正在运行，但多个虚拟交换机端口配置异常

### 🛠️ 解决方案

#### 1. 修复Hyper-V虚拟交换机配置
```powershell
# 以管理员身份运行PowerShell，执行以下命令：
Get-VMSwitch | Remove-VMSwitch -Force
# 然后重新创建虚拟交换机
New-VMSwitch -Name "Default Switch" -SwitchType Internal
```

#### 2. 禁用不必要的Hyper-V服务（如果不需要虚拟化）
```powershell
# 停止Hyper-V主机计算服务
Stop-Service vmcompute -Force
Set-Service vmcompute -StartupType Disabled
```

#### 3. 启用蓝屏转储文件记录
```powershell
# 配置系统生成蓝屏转储文件以便后续分析
wmic recoveros set DebugInfoType = 1
```

#### 4. 检查系统完整性
```powershell
# 运行系统文件检查
sfc /scannow
# 运行DISM修复
DISM /Online /Cleanup-Image /RestoreHealth
```
